# Employee-Salary-Demographics-Analysis
Data analysis project exploring employee salary patterns based on gender, education, city, and joining year using Python (Pandas, Matplotlib, Seaborn).
Project Overview

This project explores employee data to uncover patterns between salary level (Payment Tier) and key factors such as gender, education level, city, and joining year.

The goal is to practice real-world data analysis using Python (Pandas, Matplotlib, Seaborn) 


Objectives
Understand how employee attributes affect salary level
Analyze distributions across gender, education, and city
Identify patterns in high-paying employees
Practice data filtering, grouping, and visualization
Build a beginner-friendly data analysis project for portfolio

Tools that i used
Tools & Libraries Used
Python 
Pandas (data manipulation)
Matplotlib (visualization)
Seaborn (advanced visualization)
